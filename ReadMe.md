Description:
Within the game Word Par, it offers users the ability to play a word guessing game that is randomly selected through a database. Following their guesses, an AI API will be implemented that will figure out the points for each user. When the user accesses the home page after logging in to their account, they will be greated with a leaderboard that shows the top 3 players in addition to their current ranking and points. The leaderboard will be updated each day. When a user selects play, they will be directed to the game and have a word selected for them to guess which will show them the amount of characters the word is.
